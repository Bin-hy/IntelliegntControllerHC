# 项目需求
这个项目是一个基于 Ros2 + QT 实现的上位机控制系统。

# 下位机设备信息描述

## 下位机1： duco 机器臂
我们需要控制duco的机器臂，控制执行导指定位置。

## 下位机2：orbbec 相机
我们需要连接控制多个不同型号orbbec相机，采集相机的多个摄像头数据，主要需要记录图片的深度信息，保存到每个任务的记录中。
同时扩展任务： 相机需要检查机器臂是否运动异常，如果异常需要指引机器臂运动到正确的位置，同时需要及时通知用户。
## 下位机3： Lhand 灵巧手
我们需要连接控制Lhand 灵巧手，控制灵巧手执行指定动作。

# 任务描述
我们可以创建任务，每个步骤中指定不同类型的下位机去执行他们独特的控制指令。包括机器臂的使能，上电，下电，移动到指定位置，相机的采集，深度信息的处理，Lhand 灵巧手的执行动作。

为了华为的耳机装配检测实现自动化执行任务记录信息，具备登录鉴权，3级角色模型。

# 权限管理部分
我们需要实现3级角色模型，分别是：
操作员、维护人员、管理员

有关软件开发的要求如下：

账号管理
1、设备具有操作员、维护人员、管理员三级账号和权限管理功能，
根据职责区分权限。
2、默认账户应可重命名或删除，默认口令可修改。

管理员权限
可对设备的用户账号（或角色）的权限分配及更改。共享访问不能有共享文件夹。如不能满足，文件夹必须具备可设置权限访问功能。

账号口令：
账号口令可修改，符合复杂度要求（最少 8 位字符，包括大写、小
写、数字及特殊符号其中三种及以上）。

远程访问
禁止对外提供服务和能够被远程访问的进程使用 root 账户（或等同 root）权限运行。

管理权限
1、供应商提供用户面和管理面的责任矩阵清单；
2、用户面和管理面分离，禁止从用户面直接登录连接设备管理接口（不支持独立管理面的产品除外）。

访问日志
1、对于登录设备进行运维的进程应具有登录日志存储功能；
2、日志具有区分登录成功、失败的标记；
3、只有管理员账号具备删除日志的权限；
4、保留正常业务场景下 6 个月的登录日志。

业务系统
1、系统应配置并启用限制非法登录次数策略；
2、系统应配置并启用登录连接超时自动退出策略，具有登录后一
定时间无操作自动退出或账户锁定功能。

其他
1、禁止存在可绕过系统安全机制（认证、权限控制、日志记录）
对设备、系统或数据进行访问的功能（如甲方无法管理的固定口令
/隐藏帐号机制）;
2、禁止系统账号、密码硬编码在系统代码中。

需明确所有的命令/参数、软件端口（Web、telnet、SSH、Console、RDP、SNMP）等接入方式（包括但不限于设备的生产调测、维护用途），所有接入方式需提供书面说明。


操作流程示意
（以下为当前方案示意，如有更好方案可以提出优化，以达成实际效果为准）
步骤一 仿生手指涂抹（耳垢油获取和三指涂抹可以有其他等效替代方案，须经需
求方同意）
通过动捕手套+上位机的方式（动捕手套用于大动作框架的粗调，上位机用于局部
动作的精修，下同），操控仿生手移动到点胶机喷头下；通过上位机控制点胶机输出定
量耳垢油（0.01g）到仿生手；仿生手三指相互揉搓涂抹，使耳垢油尽量均匀分布在三
指指腹。

步骤二 人工耳涂抹
通过动捕手套+上位机控制拇指、食指与中指三指完全张开，依次控制手指指腹按
压耳甲腔后旋转 90 度，使耳甲腔尽量均匀分布耳垢油。

步骤三 耳机拿取&佩戴
通过动捕手套+上位机操控仿生手夹取耳机并佩戴至人工耳耳甲腔位置，并顺时针
与逆时针方向均旋转 30°，使耳包与耳甲腔充分接触。

步骤四 耳机取回
通过动捕手套+上位机操控仿生手从人工耳位置取下耳机，并放回至耳机盒内

步骤五 清洗还原（清洗还原可以有其他等效替代方案，须经需求方同意）
通过控制升降平台上升，使耳朵下降到超声波清洗器液面以下，清洗 1-3 分钟；
然后使用吹风筒对人工耳进行烘干 1-3 分钟；把人工耳放置到载物台中，用于下轮涂
抹佩戴测试；操控仿生手对其自身进行类似清洗烘干操作。
