## 1. 系统概述

### 1.1 产品定位

本软件为工业级上位机控制系统，面向实验室耳机装配检测场景，用于协调管理 DUCO 协作机器人、DH116 L 型灵巧手、Orbbec 深度相机、UDEXREAL 动捕手套及升降平台等自动化设备。系统通过统一的图形化界面（GUI），实现设备状态显示、动作序列编排、自动化任务执行及数据记录功能。

### 1.2 主要功能

| 功能模块 | 说明 |
|----------|------|
| 设备状态监控 | 实时显示机器臂关节角度、笛卡尔坐标、温度、电流；灵巧手关节状态；相机连接状态；升降平台位置 |
| 3D 可视化 | 基于 Qt3D/OpenGL 的机器人三维模型实时渲染，包含机器臂 + 灵巧手联合 URDF 模型 |
| 任务管理 | 创建、编辑、保存、加载、执行多步骤自动化任务序列，支持多轮次循环执行 |
| 手动控制 | 机器臂点动(Jog)、关节控制；灵巧手单关节/全关节控制；升降平台升降控制 |
| 视觉采集 | 多相机实时彩色/深度/红外图像显示，深度测量，图像保存 |
| 碰撞检测 | 基于点云的实时碰撞检测，多级告警，自动暂停 |
| 动捕手套 | 接收 UDEXREAL 手套关节数据，用于灵巧手动作示教 |
| 账号管理 | 三级角色（操作员/维护人员/管理员），安全认证与权限控制 |
| 日志审计 | 登录日志记录（成功/失败），6 个月自动保留 |
| 数据导出 | 任务照片、深度测量数据、耳机检测数据 CSV 导出 |

### 1.3 适用场景

- 华为耳机装配检测自动化执行
- 仿生手耳垢油涂抹、人工耳涂抹
- 耳机拿取与佩戴测试
- 清洗还原流程自动化

## 3. 系统架构

### 3.1 分层架构

```
┌───────────────────────────────────────────────────────┐
│                   用户界面层 (UI Layer)                  │
│            ui_app — Qt5 GUI 应用程序                     │
│  ┌─────────┬──────────┬──────────┬─────────┬─────────┐ │
│  │ 3D可视化 │ 任务管理  │ 手动控制  │ 视觉显示 │ 管理面板 │ │
│  └─────────┴──────────┴──────────┴─────────┴─────────┘ │
├───────────────────────────────────────────────────────┤
│               系统控制层 (Control Layer)                 │
│         system_controller — 中央调度器                    │
│     ┌──────────────────────────────────────────┐       │
│     │ 任务编排 │ 设备代理 │ 状态管理 │ 异常处理  │       │
│     └──────────────────────────────────────────┘       │
├───────────────────────────────────────────────────────┤
│                驱动层 (Driver Layer)                     │
│  ┌───────────┬──────────┬──────────┬────────┬───────┐ │
│  │duco_ros   │lhandpro  │vision    │glove   │lift   │ │
│  │_driver    │_service  │_server   │_node   │_server│ │
│  │(机器臂)   │(灵巧手)  │(视觉)    │(手套)  │(升降台)│ │
│  └───────────┴──────────┴──────────┴────────┴───────┘ │
├───────────────────────────────────────────────────────┤
│               硬件层 (Hardware Layer)                    │
│  DUCO GCR5  │ DH116 Hand │ Orbbec Camera │ Lift │ Glove│
│  (TCP/IP)   │ (EtherCAT) │ (USB 3.0)     │(RS485)│(UDP)│
└───────────────────────────────────────────────────────┘
```

### 3.2 节点启动顺序

系统通过统一启动文件 `unified.launch.py` 按以下顺序启动：

| 顺序 | 节点名称 | 功能 | 启动延迟 |
|------|----------|------|----------|
| 1 | vision_server | 相机驱动 + 图像保存 + 深度测量 | 即时 |
| 2 | duco_ros_driver | 机器臂驱动（发布 robot_state） | 即时 |
| 3 | robot_state_publisher | TF 坐标变换发布 | 即时 |
| 4 | lhandpro_service | 灵巧手 EtherCAT 驱动 | 即时 |
| 5 | lhandpro_state_publisher | 灵巧手关节状态发布 | 即时 |
| 6 | lift_server | 升降平台 Modbus RTU 驱动 | 即时 |
| 7 | system_controller | 中央调度器 | 即时 |
| 8 | ui_app | Qt5 图形界面 | 延迟 3 秒 |

### 3.3 通信架构

```
UI App (Qt5)
    ↓ /ui/request_move, /ui/request_control, /ui/request_io  (服务调用)
    ↓ execute_task  (动作)
System Controller (中央调度器)
    ├─→ /duco_robot/robot_move|robot_control|robot_io_control  → duco_ros_driver → DUCO 机器臂
    ├─→ /lhandpro_service/* (21 个服务)                        → lhandpro_service → DH116 灵巧手
    ├─→ /image_saver/save_image                                → vision_server   → Orbbec 相机
    ├─→ /depth_measure/measure                                 → vision_server   → 深度测量
    └─→ /lift_server/lift_control                              → lift_server     → 升降平台
```

## 4. 功能说明

### 4.1 主界面布局

软件主界面采用 `QSplitter` 分割布局，包含以下区域：

| 区域 | 内容 |
|------|------|
| **顶部栏** | 系统心跳状态指示灯、当前登录用户信息、语言切换（中/英）、用户菜单（修改密码/注销） |
| **中央区域** | 3D 机器人可视化渲染窗口（Qt3D/OpenGL），实时显示机器臂 + 灵巧手联合模型的姿态 |
| **右侧面板** | 相机实时画面显示（彩色/深度/红外切换），设备信息面板，任务操作按钮 |
| **底部选项卡** | 电源控制、运动控制、IO 控制、灵巧手控制、动捕手套、管理员控制台 |

### 4.2 设备状态监控

系统实时订阅并显示以下设备状态：

**机器臂状态：**
- 6 轴关节角度（期望值/实际值）
- 笛卡尔坐标（X/Y/Z 位置 + RX/RY/RZ 姿态）
- 各关节温度和电流
- 机器人状态码（STATE_ENABLE = 6 为可运动状态）
- 碰撞检测信号、急停信号
- 驱动器温度

**灵巧手状态：**
- 6 个电机实时角度
- 16 个关节位置（通过 URDF 映射）
- 设备连接状态（ready / error / disconnected）

**相机状态：**
- 多相机自动发现与连接状态
- 实时图像流（彩色/深度/红外）

**升降平台状态：**
- 编码器位置（脉冲值，1cm = 10000 脉冲）
- 运行状态

### 4.3 3D 可视化

- 加载联合 URDF 模型 `duco_gcr5_910_with_dh116_lhand.urdf`
- 通过 `/joint_states` 话题实时驱动模型关节
- 通过 `/tf` 和 `/tf_static` 实现坐标变换
- 支持鼠标旋转、缩放、平移操作
- 点云可视化显示

## 5. 账号与权限管理

### 5.1 三级角色模型

| 角色 | 英文标识 | 权限范围 |
|------|----------|----------|
| **操作员** | Operator | 基础操作：上电/使能/去使能/下电、启动/停止任务、查看设备状态 |
| **维护人员** | Maintainer | 操作员权限 + 参数修改、设备校准、查看日志 |
| **管理员** | Admin | 全部权限：用户管理（创建/删除/重命名/锁定/解锁用户）、删除日志与照片、权限分配 |

### 5.2 账号管理功能

| 功能 | 说明 |
|------|------|
| 创建账号 | 管理员可创建新用户，指定角色 |
| 删除账号 | 管理员可删除非自身账号 |
| 重命名账号 | 管理员可修改用户名 |
| 锁定/解锁 | 管理员可手动锁定或解锁账号 |
| 修改口令 | 所有用户可修改自身口令；管理员可重置他人口令 |
| 强制改密 | 管理员可标记用户下次登录时强制修改密码 |

### 5.3 默认账号

| 账号 | 初始口令 | 角色 | 备注 |
|------|----------|------|------|
| admin | admin@123 | 管理员 | 首次登录强制修改密码；可重命名或删除 |

> **注意**：默认口令仅用于首次登录，系统强制要求修改为符合复杂度要求的新口令。

### 5.4 口令复杂度要求

- 最少 **8 位**字符
- 须包含以下四类中的**至少三类**：
  - 大写字母 (A-Z)
  - 小写字母 (a-z)
  - 数字 (0-9)
  - 特殊符号 (!@#$%^&* 等)

### 5.5 口令存储安全

- 采用 **SHA-256** 算法加盐哈希存储
- 每个用户使用独立的 **16 字节随机盐值**
- 用户数据文件存储于 `~/.secure/users.dat`
- 文件权限硬化为 `0600`（仅所有者可读写）
- 目录权限设置为 `0700`
- **禁止**在代码中硬编码系统账号与密码

## 6. 安全机制

### 6.1 登录安全

| 机制 | 说明 |
|------|------|
| 非法登录限制 | 连续 **3 次**登录失败后，账号自动锁定 **10 分钟** |
| 空闲超时退出 | 登录后 **10 分钟**无鼠标/键盘操作，自动退出并返回登录界面 |
| 非 root 运行 | 程序启动时检测用户身份，**禁止以 root 权限运行** |

### 6.2 登录日志

| 项目 | 说明 |
|------|------|
| 存储位置 | `~/.logs/auth_YYYY_MM.log` |
| 记录内容 | 时间戳(UTC)、用户名、成功/失败状态、失败原因、来源 |
| 保留时长 | 自动保留 **6 个月**，超期自动清理 |
| 删除权限 | 仅管理员具备删除日志权限 |
| 查看方式 | 管理员控制台内置日志查看与筛选功能 |

### 6.3 用户面与管理面分离

- **用户面**（操作员/维护人员）：仅可进行设备操作和任务执行，无法访问管理功能
- **管理面**（管理员）：通过底部"管理员控制台"选项卡访问用户管理、日志管理等功能
- UI 控件根据当前角色**动态启用/禁用**，无法从用户面直接访问管理接口

### 6.4 文件访问安全

- 用户数据文件 (`users.dat`) 权限：`0600`
- 日志文件权限：`0600`
- 数据目录权限：`0700`
- 无共享文件夹机制

## 7. 任务管理

### 7.1 任务概念

任务（Task）是一组有序的动作步骤序列，可自动化执行多轮次循环。每个步骤指定目标设备及其控制指令。

### 7.2 任务配置

| 字段 | 说明 |
|------|------|
| task_name | 任务名称 |
| task_id | 唯一标识 |
| exec_rounds | 执行轮次 |
| collision_camera_sn | 碰撞检测使用的相机序列号（可选） |
| device_checks | 任务执行前的设备检查列表 |
| task_seqs | 步骤序列 |

### 7.3 步骤类型

| 步骤类型 (type) | 说明 | 关键参数 |
|-----------------|------|----------|
| `arm` | 机器臂运动 | arm_command（movej/movel）、arm_pos（关节角度）、arm_cart_pos（笛卡尔坐标）、arm_velocity、arm_accel |
| `lhand` / `rhand` | 灵巧手动作 | hand_pos（6 个电机目标位置） |
| `camera` | 相机拍照 | camera_type（color/depth/ir）、device_sn |
| `io` | IO 控制 | io_type（0=标准/1=工具）、io_port、io_value |
| `lift` | 升降平台 | lift_command（move_up/move_down/stop/position_move 等）、lift_speed_rpm、lift_target_pulses |
| `control` | 设备控制 | control_target（arm/lhand/rhand/lift）、control_command（poweron/enable/disable/poweroff/home） |

### 7.4 任务执行流程

```
开始任务
  ↓
设备就绪检查 (device_checks)
  ↓
配置碰撞检测相机
  ↓
┌─ 循环 exec_rounds 轮 ──────────────────┐
│   ┌─ 遍历 task_seqs 步骤 ────────────┐  │
│   │  执行当前步骤                      │  │
│   │  等待延迟 (delay_ms)              │  │
│   │  检查暂停/取消信号                 │  │
│   │  检查碰撞紧急状态                  │  │
│   │  ↓ 成功 → 下一步骤                │  │
│   │  ↓ 失败 → 错误处理/回退           │  │
│   └──────────────────────────────────┘  │
└─────────────────────────────────────────┘
  ↓
任务完成 / 反馈结果
```

### 7.5 任务控制

| 操作 | 接口 | 说明 |
|------|------|------|
| 启动任务 | `execute_task` 动作 | 发送 TaskConfig 开始执行 |
| 暂停/恢复 | `/system/pause_task` 服务 | SetBool: true=暂停, false=恢复 |
| 取消任务 | 动作取消 (cancel_goal) | 通过 ROS2 动作取消机制 |

## 8. 设备控制

### 8.1 DUCO 机器臂控制

**电源与使能控制：**

| 操作 | 命令 | 说明 |
|------|------|------|
| 上电 | poweron | 接通机器臂伺服电源 |
| 使能 | enable | 使能关节，进入可运动状态 (state=6) |
| 去使能 | disable | 去使能关节 |
| 下电 | poweroff | 断开伺服电源 |

**运动控制：**

| 运动模式 | 命令 | 说明 |
|----------|------|------|
| 关节运动 | movej | 指定 6 个关节角度（度），速度（度/秒），加速度（度/秒²） |
| 关节运动(双精度) | movej2 | 高精度关节运动，失败时自动回退到 movej |
| 直线运动 | movel | 指定笛卡尔坐标 (X/Y/Z mm + RX/RY/RZ 度)，速度（mm/s） |
| 位姿运动 | movejpose | 关节空间到达指定笛卡尔位姿 |

**IO 控制：**

| 类型 | 端口范围 | 说明 |
|------|----------|------|
| 标准 IO (type=0) | 0–15 | 通用数字 IO |
| 工具 IO (type=1) | 0–1 | 末端工具 IO |

### 8.2 DH116 灵巧手控制

灵巧手通过 EtherCAT 协议控制，支持 6 个独立电机，映射到 16 个关节位置。

| 功能分类 | 服务名称 | 说明 |
|----------|----------|------|
| 使能控制 | set_enable | 启用/禁用指定电机 |
| 位置控制 | set_position / set_all_position | 设置单个/全部电机目标位置 |
| 运动执行 | move_motors | 执行已设置的目标位置 |
| 回零 | home_motors | 电机回零操作 |
| 角度控制 | set_angle | 设置指定关节角度 |
| 状态查询 | get_now_angle / get_now_position | 获取当前角度/位置 |
| 速度控制 | set_angular_velocity / set_position_velocity | 设置运动速度 |
| 电流控制 | set_max_current / get_now_current | 设置最大电流/获取当前电流 |
| 模式控制 | set_control_mode / get_control_mode | 设置/获取控制模式 |

> **注意**：EtherCAT 通信需要 `cap_net_raw` 网络权限。

### 8.3 升���平台控制

升降平台通过 RS485 Modbus RTU 协议控制，支持以下操作：

| 命令 | 说明 |
|------|------|
| enable | 使能电机并执行回零 |
| set_target | 设置目标位置（脉冲值）和速度（RPM） |
| step_up | 触发上升运动 |
| step_down | 触发下降运动 |
| disable | 去使能电机 |
| get_position | 获取当前编码器位置 |
| status | 查询平台状态 |

位置换算：**1 cm = 10000 脉冲**

升降平台同时集成 DUCO 机器臂 IO 控制：
- DIO 4：机械制动器（HIGH=释放，LOW=锁定）
- DIO 10：伺服使能触发

### 8.4 动捕手套

- UDEXREAL 动捕手套通过 **UDP 端口 5555** 连接
- 以 50Hz 频率采集手指关节位置数据

## 10. 碰撞检测与安全防护

### 10.1 检测原理

基于深度相机点云数据，使用**球体包围盒模型**对机器臂各连杆进行碰撞检测：

1. 接收 PointCloud2 点云数据
2. ROI 裁剪 → 去除地面（基于 TF）→ 步幅降采样
3. 自身滤除（去除机器人本体点云）
4. 计算外部点云到各连杆球体包围盒的最近距离

### 10.2 告警等级

| 等级 | 英文标识 | 说明 |
|------|----------|------|
| 安全 | safe | 无障碍物或距离充足 |
| 注意 | caution | 障碍物进入注意区域 |
| 警告 | warning | 障碍物接近危险距离 |
| 紧急 | emergency | 障碍物过近，**自动暂停任务** |
| 传感器不可用 | sensor_unavailable | 深度传感器断开或异常 |
| TF 不可用 | tf_unavailable | 坐标变换数据异常 |

### 10.3 自动防护

- 当检测到 `emergency` 状态时，`system_controller` 自动暂停当前正在执行的任务
- 碰撞状态通过 `/collision_detector/status` 话题实时发布
- RViz 可视化标记通过 `/collision_detector/markers` 发布

### 14.1 所有接入方式清单

| 接入方式 | 端口/接口 | 用途 | 方向 | 安全要求 |

> - 本系统**不提供** Web、Telnet、SSH、SNMP 等远程网络服务

### 15.1 常用调试命令


### 15.2 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 灵巧手无法连接 | EtherCAT 权限不足 | 执行 `sudo setcap cap_net_raw=ep <可执行文件路径>` |
| 3D 视图黑屏 | OpenGL 渲染异常 | 设置 `export QT_OPENGL=software` 后重启 |
| 相机未识别 | udev 规则未加载 | 执行 `sudo ./install_orbbec_env.bash`，重新插拔 USB |
| 灵巧手库加载失败 | 动态库路径缺失 | 设置 `export LD_LIBRARY_PATH=$PWD/install/lhandpro_service/lib:$LD_LIBRARY_PATH` |
| UI 启动后无数据 | 节点未完全启动 | UI 已设置 3 秒延迟启动，确认其他节点正常运行 |
| 机器臂无法运动 | 状态不是 ENABLE(6) | 检查是否已依次执行 poweron → enable |

### 16.9 选项卡一：电源控制

包含两个子区域：

#### 电源管理（Power Management）

| 按钮 | 权限 | 功能 |
|------|------|------|
| **上电** | PowerOn | 发送 `poweron` 命令接通机器臂伺服电源 |
| **使能** | ModifyParam（维护员+） | 发送 `enable` 命令使能关节，进入可运动状态（state=6） |

只读文本区域，每 100ms 自动刷新，显示以下信息：
- 6 轴关节角度（期望值 / 实际值，单位：rad）
- 笛卡尔坐标（X/Y/Z mm + RX/RY/RZ rad）
- 各关节温度和电流
- 机器人状态码（6 = ENABLE 可运动，其他值见 DUCO 文档）
- 碰撞检测告警等级（安全/注意/警告/紧急）

### 16.10 选项卡二：运动控制

此选项卡内容可滚动显示。

#### 关节运动（MoveJ）

| 控件 | 参数 | 说明 |
|------|------|------|
| J1–J7 | 双精度数字框 | 各关节目标角度，范围 -360° ~ +360°，步进 1°，精度 3 位小数 |
| **获取当前** | 按钮 | 从 ROS 实时读取当前各关节角度填入输入框（用于记录当前姿态） |
| **执行 MoveJ** | 按钮 | 发送 `movej2` 命令（失败自动降级为 `movej`），以设定速度和加速度运动到目标关节角度 |

#### 笛卡尔运动（MoveL）

| 控件 | 参数 | 说明 |
|------|------|------|
| X/Y/Z | 双精度数字框 | 目标位置（毫米），范围 -3000 ~ +3000 mm，步进 1 mm |
| RX/RY/RZ | 双精度数字框 | 目标姿态（欧拉角，度），范围 -360° ~ +360°，步进 1° |

#### 运动参数（Motion Parameters）

| 控件 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| **速度** | 0.2 | 0.01–2.0 | MoveJ 单位 rad/s；MoveL 单位 m/s |
| **加速度** | 0.5 | 0.01–5.0 | 单位 m/s²（MoveL）或 rad/s²（MoveJ） |

> **安全限制**：操作员（Operator）角色速度上限自动限制为 0.2 m/s、加速度 0.5 m/s²，即使输入更大值也会被截断；维护员和管理员无此限制。

### 16.11 选项卡三：IO 控制

包含上方 IO 控制面板和下方升降平台控制区域。

#### IO 控制区

**分组选择栏：**

| 控件 | 说明 |
|------|------|
| **IO 分组** 下拉框 | 切换显示的 IO 端口组：标准 DIO (1-10) / 标准 DIO (11-16) / 工具 IO (1-2) / 功能 IO (1-8，只读） |
| **刷新状态** | 读取当前所选分组所有端口的 DO/DI 状态（每端口间隔 150ms 错峰请求） |
| **全部关闭** | 将当前分组所有 DO 输出设为 LOW（关闭），功能 IO 组不可用 |

**IO 状态表格（每行一个端口）：**

| 列 | 说明 |
|----|------|
| 端口 | 端口编号 |
| 名称 | 端口功能名称（标准 DIO 1-10 含预设名称，见下表） |
| DO 状态 | 数字输出状态：ON（绿）/ OFF（灰）/ N/A（灰）/ ERR（红）/ --（未读取） |
| DI 状态 | 数字输入状态：HIGH（绿）/ LOW（灰）/ N/A（灰） |
| **启动（ON）** | 将该端口 DO 设为 HIGH（仅标准 IO 和工具 IO，功能 IO 隐藏） |
| **停止（OFF）** | 将��端口 DO 设为 LOW |

**标准 DIO 预设名称（端口 1-10）：**

| 端口 | 名称 |
|------|------|
| 1 | 清洗机 |
| 2 | 左侧吹风机 |
| 3 | 右侧烘干机 |
| 4 | 升降平台解锁（抱闸释放，HIGH=释放） |
| 5 | 黄灯 |
| 6 | 绿灯 |
| 7 | 红灯 |
| 8 | 蜂鸣器 |
| 9 | 点胶机 |
| 10 | 升降平台回原点（DIO 10，HIGH=触发） |

#### 升降平台控制（Lift Platform Control）

| 控件 | 类型 | 参数 | 说明 |
|------|------|------|------|
| **目标位置** | 双精度数字框 | 0–32 cm，步进 0.5 cm | 升降目标位置；1 cm = 10000 脉冲 |
| **速度** | 整数数字框 | 1–65535 RPM | 电机转速 |
| **使能/回原点** | 按钮 | — | 完整回零流程：释放抱闸 (DO4 HIGH) → 伺服使能 → 触发 DIO10 回零 → 等待 3s → 设置目标 → 触发运动；到位后自动轮询位置并显示 |
| **停止** | 红色按钮 | — | 立即停止：去使能伺服 → DIO10 LOW → 锁定抱闸 (DO4 LOW) |
| 状态标签 | 只读 | — | 显示当前操作阶段（解锁抱闸中 / 使能中 / 回原点中 / 移动中 / 位置: X cm / 到位 / 超时 / 已停止） |

> **操作说明**：点击「使能/回原点」后，系统自动按以下步骤执行，无需手动干预：
> 1. DO4 设为 HIGH（释放机械抱闸）
> 2. 发送 `enable` 命令（伺服上电并回零）
> 3. 1s 后触发 DIO10（启动回零动作）
> 4. 3s 后设置目标位置（脉冲）并触发运动
> 5. 每 500ms 轮询位置，位置稳定 3 次后自动停止（去使能 + 锁定抱闸）
> 6. 超时 30s 未到位则自动停止
