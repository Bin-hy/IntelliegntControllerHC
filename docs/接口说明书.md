## 1. 接口总览

### 1.1 接口包一览

| 包名                    | 说明                    | 接口数量                     |
| --------------------- | --------------------- | ------------------------ |
| `common_msgs`         | 系统通用消息、服务与动作定义        | 8 msg + 1 srv + 1 action |
| `duco_msg`            | DUCO 机器臂消息与服务定义       | 3 msg + 6 srv            |
| `lhandpro_interfaces` | DH116 灵巧手服务定义（左/右手共用） | 21 srv                   |
| `vision_server`       | 视觉系统服务定义              | 4 srv                    |
| `lift_server`         | 升降平台服务定义              | 1 srv                    |

### 1.2 通信方式说明

| 通信模式             | 说明                | 适用场景        |
| ---------------- | ----------------- | ----------- |
| **话题 (Topic)**   | 发布-订阅模式，单向异步      | 状态上报、传感器数据流 |
| **服务 (Service)** | 请求-响应模式，同步调用      | 设备控制指令、状态查询 |
| **动作 (Action)**  | 请求-反馈-结果模式，异步长时任务 | 自动化任务执行     |

## 2. 消息定义 (msg)

### 2.1 common\_msgs/msg/TaskConfig

**用途**：定义自动化任务的完整配置。

```
string   task_name              # 任务名称
int32    task_id                # 任务唯一标识
int64    created_time           # 创建时间戳
int32    exec_rounds            # 执行轮次
string   collision_camera_sn    # 碰撞检测相机序列号（空 = 默认）
TaskDeviceCheck[] device_checks # 任务执行前设备检查列表
TaskStep[]        task_seqs     # 任务步骤序列
```

### 2.2 common\_msgs/msg/TaskStep

**用途**：定义任务中的单个执行步骤，支持多种设备类型。

```
string    name                  # 步骤名称
string    type                  # 步骤类型：arm / lhand / rhand / camera / io / lift / control
string    device_sn             # 目标设备序列号

# ── 机器臂步骤字段 (type = arm) ──
string    arm_command            # 运动命令："movej" 或 "movel"（默认 movej）
float64[] arm_pos                # 关节角度（度），MoveJ 模式 6 个关节
float64[] arm_cart_pos           # 笛卡尔坐标：X,Y,Z (mm); RX,RY,RZ (度)
float64   arm_velocity           # MoveJ: 度/秒; MoveL: mm/秒
float64   arm_accel              # MoveJ: 度/秒²; MoveL: mm/秒²

# ── 灵巧手步骤字段 (type = lhand / rhand) ──
int32[]   hand_pos               # 6 个电机目标位置

# ── 相机步骤字段 (type = camera) ──
string[]  camera_type            # 采集类型列表：color / depth / ir

# ── IO 控制步骤字段 (type = io) ──
int8      io_type                # IO 类型：0=标准IO(端口1-16), 1=工具IO(端口1-2)
int8      io_port                # IO 端口号
bool      io_value               # 输出值：true=高电平, false=低电平
int32     delay_ms               # 步骤执行后的延迟时间（毫秒）

# ── 升降平台步骤字段 (type = lift) ──
string    lift_command           # 命令：move_up / move_down / stop / position_move /
                                 #       position_next / position_stop
int32     lift_speed_rpm         # 速度（RPM）
int32     lift_target_pulses     # 目标位置（脉冲值，1cm = 10000 脉冲）
int32     lift_accel_ms          # 加速时间（毫秒，默认 1000）
int32     lift_decel_ms          # 减速时间（毫秒，默认 1000）

# ── 设备控制步骤字段 (type = control) ──
string    control_target         # 控制对象：arm / lhand / rhand / lift
string    control_command        # 控制命令：poweron / enable / disable / poweroff / home
```

### 2.3 common\_msgs/msg/TaskDeviceCheck

**用途**：任务执行前的设备就绪检查项。

```
string device_type               # 设备类型
string device_usage              # 设备用途

string device_model              # 设备型号

```
string device_type               # 设备类型（如 "camera", "lhand", "glove"）
string device_usage              # 设备用途
string device_name               # 设备名称
string device_sn                 # 设备序列号
string device_model              # 设备型号
string status                    # 状态值："ready" / "error" / "disconnected"
string topic_prefix              # 相机命名空间前缀，如 "/camera" 或 "/camera_1"

### 2.5 common\_msgs/msg/CollisionStatus

**用途**：碰撞检测状态消息。

```

                                 #       sensor_unavailable / tf_unavailable
float64 min_distance             # 最近障碍物到机器人连杆表面的距离（米）
                                 # 999 = 无障碍物
string  nearest_link             # 最近的机器人连杆名称

int32   roi_center_v             # 测量中心像素 V 坐标
int32   valid_points             # 用于测量的有效深度像素数

string  camera_ns                # 来源相��命名空间
```

### 2.9 duco\_msg/msg/DucoRobotState

float64[7] joint_expect_position     # 关节期望位置
float64[7] joint_expect_velocity     # 关节期望速度
float64[7] joint_expect_accelera     # 关节期望加速度

float64[7] joint_actual_velocity     # 关节实际速度
float64[7] joint_actual_accelera     # 关节实际加速度
float64[7] joint_actual_current      # 关节实际电流（安培）
float64[7] joint_temperature         # 关节温度（°C）
float64[7] driver_temperature        # 驱动器温度（°C）

# ── 笛卡尔数据 ──
float64[7] cart_expect_position      # 笛卡尔期望位置
float64[7] cart_expect_velocity      # 笛卡尔期望速度
float64[7] cart_expect_accelera      # 笛卡尔期望加速度
float64[7] cart_actual_position      # 笛卡尔实际位置
float64[7] cart_actual_velocity      # 笛卡尔实际速度
float64[7] cart_actual_accelera      # 笛卡尔实际加速度

# ── 状态标志 ──
bool[7]    slave_ready               # 各从站就绪标志
bool       collision                 # 碰撞检测标志
int8       collision_axis            # 碰撞轴号
bool       emc_stop_signal           # 急停信号
int8       robot_state               # 机器人状态码（6 = ENABLE 可运动）
int32      robot_error               # 错误码

## 3. 服务定义 (srv)

### 3.1 duco\_msg/srv/RobotMove

**用途**：控制机器臂运动，支持关节运动和直线运动。

**请求 (Request)：**

| 字段       | 类型         | 说明                                              |
| -------- | ---------- | ----------------------------------------------- |
| command  | string     | 运动命令：`movej` / `movej2` / `movel` / `movejpose` |
| arm\_num | int8       | 臂编号（默认 0）                                       |
| p        | float32\[] | 笛卡尔目标位置 \[X, Y, Z, RX, RY, RZ]（movel 使用）        |
| q        | float32\[] | 关节目标角度 \[J1, J2, J3, J4, J5, J6]（movej 使用）      |
| v        | float32    | 速度（movej: 度/秒; movel: mm/秒）                     |
| a        | float32    | 加速度（movej: 度/秒²; movel: mm/秒²）                  |
| r        | float32    | 过渡半径                                            |
| tool     | string     | 工具坐标系名称                                         |
| wobj     | string     | 工件坐标系名称                                         |
| block    | bool       | 是否阻塞等待完成                                        |

**响应 (Response)：**

| 字段       | 类型     | 说明     |
| -------- | ------ | ------ |
| response | string | 执行结果信息 |

**command 取值说明：**

| 命令        | 说明                    | 必要参数    |
| --------- | --------------------- | ------- |
| movej     | 关节空间运动                | q, v, a |
| movej2    | 高精度关节运动（失败自动回退 movej） | q, v, a |
| movel     | 笛卡尔直线运动               | p, v, a |
| movejpose | 关节空间到达笛卡尔位姿           | p, v, a |

### 3.2 duco\_msg/srv/RobotControl

**用途**：机器臂电源与使能控制。

**请求 (Request)：**

| 字段       | 类型     | 说明                                                 |

| arm\_num | int8   | 臂编号                                                |

**响应 (Response)：**

| 字段       | 类型     | 说明     |
| -------- | ------ | ------ |
| response | string | 执行结果信息 |

**操作顺序**：`poweron` → `enable` → (运动操作) → `disable` → `poweroff`

### 3.3 duco\_msg/srv/RobotIoControl

**用途**：机器臂 IO 端口控制。

**请求 (Request)：**

| block    | bool   | 是否阻塞                    |

**响应 (Response)：**

| 字段       | 类型     | 说明                |
| -------- | ------ | ----------------- |
| response | string | 执行结果（getIo 返回当前值） |

### 3.9 lhandpro\_interfaces 服务定义

DH116 灵巧手提供 21 个服务接口，按功能分类如下：

#### 3.9.1 使能控制

**SetEnable.srv** — 启用/禁用指定电机

| 方向       | 字段        | 类型    | 说明           |
| -------- | --------- | ----- | ------------ |
| Request  | joint\_id | int32 | 电机编号 (0–5)   |
| Request  | enable    | int32 | 1=使能, 0=禁用   |
| Response | result    | int32 | 0=成功, 非0=错误码 |

#### 3.9.2 位置控制

**SetPosition.srv** — 设置单个电机目标位置

| 方向       | 字段        | 类型    | 说明         |
| -------- | --------- | ----- | ---------- |

| Response | result    | int32 | 执行结果       |

## 7. 动作接口 (Actions)

### 7.1 动作清单

| 动作名称           | 类型                       | 服务端                | 客户端     | 说明      |
| -------------- | ------------------------ | ------------------ | ------- | ------- |
| `execute_task` | common\_msgs/ExecuteTask | system\_controller | ui\_app | 自动化任务执行 |

### 7.2 执行流程详解

**阶段 1 — 任务初始化：**

1. 接收 TaskConfig 目标
2. 检查系统是否忙碌 (`is_busy_` 原子变量)
3. 验证设备就绪状态（通过 `/system/device_status`）
4. 配置碰撞检测相机（发布到 `/collision_detector/set_topic`）

**阶段 2 — 步骤循环执行：**

1. 遍历 `task_seqs` 中的每个步骤
2. 根据步骤 `type` 调用对应硬件服务
3. 每步骤完成后发送 Feedback 更新进度
4. 执行步骤间延迟 (`delay_ms`)
5. 检查暂停(`is_paused_`)和取消信号

**阶段 3 — 异常处理：**

- 碰撞紧急状态：自动暂停，等待解除
- 步骤执行失败：记录错误，尝试回退（如 movej2→movej）
- 任务取消：响应 ROS2 动作取消请求

**阶段 4 — 完成：**

- 返回 Result（success/failure + message）
- 释放 `is_busy_` 状态
