视觉标定 Tab 使用指南（安装调试人员）                                                                                                         
                                                                                                                                                
  调试分三步：先标手眼偏移，再调手指抓握力度，最后联调验证。                                                                                    
                                                                                                                                                
  ---                                                                                                                                           
  第一步：手眼 TF 标定（最关键）                                                                                                                
                                                                                                                                                
  这一步确定相机相对于机械臂末端手爪基座（L_base_link）的安装偏移。  
                                                                                                                                                
  初始测量（用尺子）：                                                                                                                          
  1. 测量相机光心到法兰中心的偏移：                                                                                                             
    - X：相机在法兰坐标系 X 方向的偏移（左右），单位米                                                                                          
    - Y：Y 方向偏移（前后），单位米                         
    - Z：Z 方向偏移（上下），单位米                                                                                                             
  2. 如果相机没有旋转安装，RX/RY/RZ 保持 0                                                                                                      
  3. 如果相机有倾斜角度，用量角器估算，填入对应的度数                                                                                           
                                                                                                                                                
  在 Tab 中操作：                                                                                                                               
  1. 将测量值填入 6 个输入框                                                                                                                    
  2. 点击 "发布 TF" → 系统立即生效                                                                                                              
                                                                                                                                                
  验证方法（迭代微调）：                                                                                                                        
  1. 在桌面上放一个水瓶，记住它的大致位置                                                                                                       
  2. 在彩色流画面上点击水瓶 → 出现绿色十字                                                                                                      
  3. 点击 "抓取选中目标"                                                                                                                        
  4. 观察机械臂实际到达位置与水瓶的偏差：                                                                                                       
    - 如果偏左 → 减小 X 值                                                                                                                      
    - 如果偏右 → 增大 X 值                                                                                                                      
    - 如果偏远 → 增大 Y 值                                                                                                                      
    - 如果偏近 → 减小 Y 值                                                                                                                      
    - 如果偏高 → 减小 Z 值                                                                                                                      
    - 如果偏低 → 增大 Z 值                                                                                                                      
  5. 每次调整 0.005m（5mm），重新点"发布 TF"，再测试                                                                                            
  6. 反复 3-5 轮，直到机械臂能准确到达水瓶正上方                                                                                                
                                                                                                                                                
  精度目标： 偏差 < 10mm 即可抓取成功                                                                                                           
                                                                                                                                                
  ---                                                                                                                                           
  第二步：灵巧手抓握力度调试                                                                                                                    
                                                                                                                                                
  操作流程：
  1. 先点 "全开 (0)" 确认手完全张开                                                                                                             
  2. 把水瓶放到手掌中间                                                                                                                         
  3. 依次点击预设按钮测试：                                                                                                                     
    - 轻握 (400) → 观察手指是否接触瓶身                                                                                                         
    - 中握 (600) → 观察是否夹住但不太紧                                                                                                         
    - 紧握 (800) → 观察是否牢固抓住                                                                                                             
  4. 如果某个预设值合适，记下来                                                                                                                 
  5. 如果需要微调：手动修改 M1-M6 的值，点 "发送位置"                                                                                           
                                                                                                                                                
  单独调整技巧：                                                                                                                                
  - M1（拇指侧）通常需要更大的值（提供主要夹持力）                                                                                              
  - M5/M6（小指侧）可以稍小                                                                                                                     
  - 例如：[900, 800, 700, 700, 600, 600] 比全部 800 更适合圆柱体                                                                                
                                                                                                                                                
  读取反馈：                                                                                                                                    
  - 点 "读取当前位置" 可以看到电机实际到达的位置                                                                                                
  - 如果实际值远小于设定值，说明被水瓶阻挡（正常）                                                                                              
                                                                                                                                                
  确认后保存： 点 "保存配置" 导出 YAML 文件，记录最终值                                                                                         
                                                                                                                                                
  ---                                                                                                                                           
  第三步：全流程联调                                                                                                                            
                                                                                                                                                
  1. 确保机械臂已上电使能（电源控制 Tab）
  2. 确保相机画面正常显示                                                                                                                       
  3. 在桌面上放 2-3 个水瓶                                                                                                                      
  4. 在彩色流画面上 点击你想抓的那个水瓶                                                                                                        
  5. 确认绿色十字准星在目标上                                                                                                                   
  6. 点击 "抓取选中目标"                                                                                                                        
  7. 观察完整流程：开手 → 移到上方 → 下降 → 合手 → 抬起                                                                                         
                                                                                                                                                
  常见问题排查：                                                                                                                                
                                                                                                                                                
  ┌────────────────────┬─────────────────────┬───────────────────────────────┐                                                                  
  │        现象        │        原因         │             调整              │
  ├────────────────────┼─────────────────────┼───────────────────────────────┤                                                                  
  │ 机械臂到了但位置偏 │ TF 标定不准         │ 回第一步微调 X/Y/Z            │
  ├────────────────────┼─────────────────────┼───────────────────────────────┤                                                                  
  │ 到了正确位置但抓空 │ 下降高度不够        │ 减小 launch 中 grasp_z_offset │                                                                  
  ├────────────────────┼─────────────────────┼───────────────────────────────┤                                                                  
  │ 抓到了但没夹住     │ 手指力度不够        │ 增大 hand_close 值            │                                                                  
  ├────────────────────┼─────────────────────┼───────────────────────────────┤                                                                  
  │ 深度无效报错       │ 距离太近 (<200mm)   │ 让机械臂在更高位置拍照        │
  ├────────────────────┼─────────────────────┼───────────────────────────────┤                                                                  
  │ TF 变换失败        │ 没有发布 TF         │ 点一次"发布 TF"               │
  ├────────────────────┼─────────────────────┼───────────────────────────────┤                                                                  
  │ 服务不可用         │ vision_grasp 没启动 │ 另开终端启动 launch           │
  └────────────────────┴─────────────────────┴───────────────────────────────┘                                                                  
                                                            
  ---                                                                                                                                           
  参数保存到生产配置                                        
                                                                                                                                                
  调试完成后，把最终值更新到 launch 文件中，这样下次启动不需要重新调：
                                                                                                                                                
  # 更新 vision_grasp.launch.py 中的：                                                                                                          
  # 1. static_transform_publisher 的 --x --y --z 参数（TF偏移）                                                                                 
  # 2. hand_close 参数（抓握位置）                                                                                                              
  # 3. grasp_z_offset 参数（下降偏移）                                                                                                          
                                                                                                                                                
  调试完成、参数固化后，这个 Tab 可以从 app_window.cpp 的 buildDashboard() 中注释掉。
